# Scope

Texas Hold’em only. Separate the poker engine from HTTP/UI infrastructure. Provide an anonymous nickname flow, password-protected lobbies for 2–10 players, host kick/start controls, automatic live updates, an all-player connection barrier before dealing, server-side betting and settlement, and a minimal React/TypeScript poker table.

No account authentication or external services. Nicknames persist in local storage; tab seats survive refresh using session storage. State is in memory. Visual design, profile uploads, richer notifications and production persistence can follow separately.
